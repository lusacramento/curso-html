Tags de Formatação

<strong></strong> e <b></b> (Destaques em Negrito)

<strong>: Indica que o texto tem grande importância, urgência ou gravidade (o Google e os leitores de tela prestam atenção nele).

<b>: Modifica o texto para negrito por motivos puramente estéticos, sem dar nenhuma importância real à palavra. 


        Código:
        <p>Isto é muito <strong>importante</strong>!</p>
        <p>Isto é um <negrito></b>.</p>

Exemplo:

Isto é muito importante!

Isto é um negrito.


<em></em> e <i></i> (Destaques em Itálico)

<em>: Significa Emphasis (Ênfase). Usado quando você quer enfatizar uma palavra ao ler (muda o tom de voz nos leitores de tela).

<i>: Modifica o texto para itálico para indicar termos técnicos, palavras em outros idiomas ou pensamentos, sem dar ênfase de voz. 


            Código:
            <p>Isto é uma <em>ênfase</em>!</p>
            <p>Isto é um <i>itálico</i>.</p>

Exemplo:

Isto é uma ênfase!

Isto é um itálico.


<u></u> (Sublinhado)

Avisa que o texto tem uma linha decorativa por baixo. Antigamente indicava texto sublinhado, mas hoje é usada para representar nomes próprios em chinês ou termos com erros de ortografia apontados.

Regra de ouro: Evite usar para não confundir o usuário achando que é um link (). 


            Código:
            <p>Isto é um <u>sublinhado</u>!<p>

Exemplo:

Isto é um sublinhado!

<mark></mark> (Marcador de Texto)

Funciona exatamente como uma caneta marca-texto amarela. Realça visualmente um trecho para indicar que ele é muito relevante dentro de uma pesquisa ou contexto atual. 


            Código:
            <p>A palavra a seguir está <mark>destacada</mark>!</p>

Exemplo:

A palavra a seguir está destacada!


<small></small> (Texto Secundário)

Deixa a letra um pouco menor que o texto normal. Semanticamente, serve para indicar as "letras miúdas" de um site, como avisos de direitos autorais (Copyright), termos de uso ou restrições legais. 


            Código:
            <p>Leiam sempre as <small>letras miúdas<small>!</p>

Exemplo:

Leiam sempre as letras miúdas!


<del></del> e <ins></ins> (Edições de Texto)

<del>: Significa Deleted (Deletado). Risca o texto com uma linha no meio para mostrar que aquela informação foi removida ou atualizada.

<ins>: Significa Inserted (Inserido). Sublinha o texto para mostrar que aquela informação foi adicionada recentemente ao documento. 


            Código:
            <p>
                A palavra <del>avião</del><br />
                foi alterada para <ins>barco</ins>.
            </p>

Exemplo:

A palavra avião
foi alterada para barco.


<sub></sub> e <sup></sup> (Textos Deslocados)

<sub>: Significa Subscript (Subscrito). Deixa a letra menor e rebaixada (na parte inferior). Muito usada em fórmulas químicas. Ex: H2O.

<sup>: Significa Superscript (Sobrescrito). Deixa a letra menor e elevada (na parte superior). Muito usada em potências matemáticas ou indicadores ordinais. Ex: 102 ou 3º. 


            Código:
            <p>2<sup>4</sup> é igual à 16!</p>
            <p>O CO<sub>2</sub> é prejudicial a saúde e a natureza.</p>

Exemplo:

24 é igual à 16!

O CO2 é prejudicial a saúde e a natureza.
