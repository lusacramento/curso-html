Introdução e Ambiente de Desenvolvimento

Bem-vindo à primeira página do curso. Antes de escrevermos nossa primeira linha de código, precisamos entender o que é a engrenagem da internet e preparar a nossa bancada de trabalho no sistema operacional.


O que é HTML?

Significa HyperText Markup Language (Linguagem de Marcação de Hipertexto). Diferente do que muitos pensam, o HTML não é uma linguagem de programação, pois não possui lógica ou processamento de dados.

O que faz: Ele funciona estritamente como a estrutura e o esqueleto de uma página web. Através de etiquetas conhecidas como tags, nós marcamos onde fica cada título, parágrafo, imagem ou link do nosso site.


O que é uma IDE e um Editor de Código?

Significa Integrated Development Environment (Ambiente de Desenvolvimento Integrado). Enquanto um editor de código simples é apenas um bloco de notas avançado, uma IDE é uma bancada de trabalho completa que traz ferramentas de automação, terminal integrado e extensões que ajudam o programador a trabalhar mais rápido.

Neste curso, utilizaremos o Visual Studio Code (VS Code), que é atualmente o editor mais popular, leve e poderoso do mercado global.


Como Instalar o VS Code no Linux Mint

No Linux Mint, a forma mais segura, oficial e recomendada para instalar o VS Code e mantê-lo sempre atualizado é adicionando o repositório oficial da Microsoft via terminal.

Passo a Passo de Instalação (Abra o Terminal):

# 1. Atualize a lista de pacotes do sistema
sudo apt update

# 2. Instale as dependências necessárias para segurança de chaves
sudo apt install apt-transport-https curl

# 3. Importe a chave de segurança oficial da Microsoft
curl -sSL https://microsoft.com | sudo gpg --dearmor -o /usr/share/keyrings/ms-vscode-keyring.gpg

# 4. Adicione o repositório oficial do VS Code às fontes do sistema
echo "deb [arch=amd64,arm64,armhf signed-by=/usr/share/keyrings/ms-vscode-keyring.gpg] https://microsoft.com stable main" | sudo tee /etc/apt/sources.get.d/vscode.list

# 5. Atualize novamente a lista de pacotes e instale o VS Code
sudo apt update
sudo apt install code

Como a Web Funciona? (O Modelo Cliente-Servidor)

Sempre que você digita um endereço no navegador, acontece uma conversa entre dois computadores na internet:

O Cliente: É o seu computador ou celular (usando o navegador). Ele faz uma requisição HTTP (um pedido) solicitando os arquivos de um site.

O Servidor: É um computador potente ligado 24h em algum lugar do mundo (como os servidores do GitHub Pages). Ele recebe o pedido, processa a informação e envia uma resposta HTTP contendo os arquivos estruturados (o seu arquivo <html>).


A Tríade da Web: HTML, CSS e JavaScript

Um site moderno e profissional é composto obrigatoriamente por três tecnologias trabalhando juntas de forma integrada:

1. HTML: É o esqueleto. Define os textos, botões e a estrutura bruta do site.

2. CSS: É a roupa e a maquiagem. Define as cores, fontes, alinhamentos, espaçamentos e deixa o site bonito e responsivo para celulares.

3. JavaScript: É o cérebro e os músculos. Define o comportamento dinâmico, animações, lógica, cliques em botões e validações em tempo real.
