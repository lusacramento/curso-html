Formulários

Para criar qualquer formulário no HTML, nós usamos uma tag mãe que define a área de captura de dados trabalhando em dupla com as tags filhas que criam os campos de digitação, caixas de seleção e botões de envio.


<form></form> (O Formulário)

Significa Form (Formulário).

O que faz: É a tag principal que envolve todos os campos de entrada de dados. Ela funciona como um envelope que agrupa as informações inseridas pelo usuário para enviá-las a um servidor.


<label></label> (Etiqueta do Campo)

Significa Label (Etiqueta/Rótulo).

O que faz: Vincula um texto explicativo a um campo <input />. Melhora a acessibilidade do site e permite que o usuário clique no texto para ativar a caixa de digitação correspondente.


<input /> (Campo de Entrada)

Significa Input (Entrada). É uma tag autocontida (não possui fechamento).

O que faz: Cria uma caixa onde o usuário pode interagir. O seu comportamento muda completamente dependendo do atributo type utilizado (como text, email, password ou number). 


            Código:
            <form action="">
                <label for="nome">Nome</label>
                <input type="text" name="nome" id="exemplo-input-nome" />
                <br />
                <label for="idade">Idade</label>
                <input type="number" name="idade" id="exemplo-input-idade">
                <br />
                <label for="email">Email</label>
                <input type="email" name="email" id="exemplo-input-email" />
                

                <label for="senha">senha</label>
                <input type="password" name="senha" />

Botões de Rádio (type="radio")

O que faz: Criados através da tag <input /> com o atributo type="radio". Permitem que o usuário escolha apenas uma única opção dentro de um grupo. Para que o grupo funcione corretamente e o navegador saiba que eles pertencem juntos, todos devem compartilhar exatamente o mesmo atributo name. 


        Código:
        <form>
            <input type="radio" id="m" name="genero" value="M">
            <label for="m">Masculino</label>
            <input type="radio" id="f" name="genero" value="F">
            <label for="f">Feminino</label>
        </form>

Caixas de Seleção (type="checkbox")

O que faz: Criados através da tag <input /> com o atributo type="checkbox". Permitem que o usuário selecione múltiplas opções ao mesmo tempo, ou marque opções independentes de "sim ou não" (como aceitar os termos de uso). 


        <form action="">
            <input type="checkbox" id="termos" name="termos">
            <label for="termos">Aceito os termos de uso</label>
        </form>

<select> e <option> (Lista Suspensa / Dropdown)

O que faz: A tag mãe <select> cria uma lista de seleção onde o usuário clica para abrir as opções ocultas. Cada item selecionável dentro dessa lista deve ser criado utilizando a tag filha <option>. Ideal para economizar espaço visual na tela. 


        Código:
        <form action="">
            <select id="pais" name="pais">
                <option value="br">Brasil</option>
                <option value="pt">Portugal</option>
                <option value="usa">Estados Unidos</option>
            </select>
        </form>

<button></button> (Botão)

Significa Button (Botão).

O que faz: Cria um botão clicável. Quando colocado dentro de um formulário, o comportamento padrão dele é disparar a ação de envio (submissão) de todos os dados preenchidos. 


        Código:
        <form action="submit">
            <button type="reset">Limpar</button>
            <button type="submit">Enviar</button>
        </form>

    <label for="css">CSS</label>

    <label for="estado">Estado:</label>

        <option value="SP">São Paulo</option>
        <option value="MG">Minas Gerais</option>
        <option value="RJ">Rio de Janeiro</option>
    </select>
    
    <button type="submit">Enviar Cadastro</button>
</form>
