Tags e Propriedades

O que é tag?

Uma tag é um comando (ou uma etiqueta) que avisa ao navegador o que cada elemento do seu site deve ser. Elas funcionam como os blocos de construção da página. Exemplo: A tag <p> avisa: "O texto a seguir é um parágrafo". A tag <img> avisa: "Aqui entra uma imagem".

O que é uma propriedade (ou atributo) de uma tag?

Uma propriedade (geralmente chamada de atributo) é uma informação extra que você coloca dentro da tag para mudar o comportamento dela ou dar uma instrução específica. Exemplo: Se a tag <a> cria um link, a propriedade href="..." serve para dizer para qual site esse link deve levar o usuário.

Diferença entre tags com fechamento e tags sem fechamento

Tags que precisam abrir e fechar:

São tags que funcionam como uma "caixa" ou um "envelope". Elas servem para guardar algo dentro delas (seja um texto ou outras tags). Você abre com <tag> e fecha colocando uma barra </tag>.

Exemplo:

 

        <h1>Meu Título</h1> (O texto fica guardado dentro da tag).

Tags que Não precisam fechar (Tags Autocontidas):

São tags que não guardam nenhum texto dentro delas. Elas servem apenas para inserir um elemento direto na página de uma vez só.

Exemplo:

 

        <img /> Ela apenas joga uma imagem na tela
        <br /> Ela apenas pula uma linha. Não existe um "conteúdo" para colocar dentro delas.

Principais Tags

<!DOCTYPE html> (A Declaração)

declaração obrigatória que deve ficar na primeiríssima linha do seu arquivo.O que faz: Ela avisa ao navegador: "Atenção, este documento foi escrito na versão mais moderna do HTML, o HTML5". Sem ela, o navegador entra em um modo antigo de compatibilidade e o site pode quebrar.


<html></html> (A Raiz do Site)

Esta é a tag mãe de todas as outras. Tudo o que existe no seu código deve ser escrito obrigatoriamente dentro dela (com exceção do doctype).

O que faz: Ela avisa onde o seu código HTML começa e onde ele termina. é também nela que você define o idioma principal da página usando a propriedade lang (ex: <html lang="pt-BR">).


<head></head> (A Cabeça Oculta)

é a "mente" do seu site. Tudo o que você coloca dentro do <head> serve para dar instruções ao navegador e aos motores de busca, ou seja, são informações que ficam invisíveis para quem acessa a página.

O que faz: Ela guarda as configurações de bastidores, como o título que aparece na aba do navegador (<title>), o formato dos acentos (<meta charset="UTF-8">), as configurações de celular e as ligações com arquivos de estilo (CSS).

<body></body> (O Corpo Visível)

Se o <head> é a mente oculta do site, o <body> é o corpo real. é a tag que guarda absolutamente tudo o que o usuário consegue ver, ler e interagir quando acessa a sua página.

O que faz: Ela funciona como uma grande tela em branco. Qualquer elemento visível do seu site deve ser colocado obrigatoriamente dentro dela.

O que vive dentro dele: é aqui que você vai colocar seus textos, títulos, parágrafos, imagens, links, botões, formulários, tabelas e vídeos.

Como o <head> e o <body> se conectam?

Eles trabalham sempre em dupla e nunca se misturam. Pense neles como os bastidores e o palco de um teatro:

O <head> são os bastidores: Configura as luzes, o idioma da peça, as regras e prepara a estrutura (invisível para o público).

O <body> é o palco: Onde os atores entram e o show realmente acontece (tudo o que o público enxerga).


<!-- --> (Comentários)

Tudo o que você escrever dentro dela será completamente ignorado pelo navegador e não vai aparecer na tela para o usuário. Ela funciona como um bloco de notas exclusivo para quem está escrevendo o código.

Para que ela serve no dia a dia?

  1. Deixar Anotações e Lembretes: Explicar para você mesmo (ou para outros programadores) o que aquela parte do código faz.
  2. Organizar o Código: Dividir o seu site em seções visuais facilitando a leitura quando o arquivo ficar muito grande.
  3. Desativar Códigos Temporariamente ("Comentar o Código"): Se você quiser testar como o site fica sem um parágrafo ou imagem, em vez de apagar o código, você o coloca dentro de um comentário. O navegador deixa de exibi-lo, mas ele continua guardado ali caso você queira usá-lo depois.

Estrutura básica do html


        <!DOCTYPE html>
        <html lang="pt-BR">
        
        <head>
            <!-- Configurações (Invisível) -->
            <meta charset="UTF-8">
            <title>Minha Página de Estudos</title>
        </head>
        
        <body>
            <!-- Conteúdo (Visível na tela) -->
            <h1>Bem-vindo ao meu resumo!</h1>
            <p>Este texto está aparecendo porque foi escrito dentro da tag body.</p>
        </body>
        
        </html>
