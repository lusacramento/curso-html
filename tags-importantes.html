Tags importantes

<h1></h1> até <h6></h6> (Títulos e Subtítulos)

São as tags usadas para definir os títulos do seu site, variando de importância do 1 ao 6.

O que faz: O <h1> é o título principal da página (o maior e mais importante). O <h2> é um subtítulo, o <h3> um sub-subtítulo, e assim por diante.

Regra de Ouro: O Google exige que cada página tenha apenas um <h1> para saber qual é o assunto principal do seu site. 


        Código:
        <h1>Isto é um título h1</h1>
        <h2>Isto é um subtítulo h2</h2>
        <h2>Isto é um subtítulo h2</h2>
        <h3>Isto é um subtítulo h3</h3>
        <h4>Isto é um subtítulo h4</h4>
        <h5>Isto é um subtítulo h5</h5>
        <h6>Isto é um subtítulo h6</h6>

Exemplo:

Isto é um título h1

Isto é um subtítulo h2

Isto é um subtítulo h3

Isto é um subtítulo h2

Isto é um subtítulo h4

Isto é um subtítulo h5
Isto é um subtítulo h6

<p></p> (Parágrafo)

É a tag padrão para criar blocos de texto comuns. 


        Código:
        <p>Isto é um parágrafo</p>

Exemplo:

Isto é um parágrafo


<br /> (Quebra de Linha)

É uma tag autocontida (não tem fechamento) usada para pular uma linha dentro de um texto.

O que faz: Se você apertar "Enter" no seu editor de código, o navegador ignora e deixa o texto na mesma linha. Para forçar o texto a ir para a linha de baixo sem criar um parágrafo novo, você joga um <br>. 


        Código:
        <p>
            Isto é uma<br />
            quebra<br />
            de<br />
            linha.
        <p>

Exemplo:

quebra

<a></a>(Link / Âncora)

É a tag usada para criar links que levam o usuário para outra página. Ela precisa obrigatoriamente de uma propriedade:

Atributo href: Abreviação de Hypertext Reference (Referência de Hipertexto). É onde você coloca o endereço do site (a URL) para onde a pessoa será enviada ao clicar. 


        Código:
        <a href="https://google.com">Ir para o Google</a>

Exemplo:

 Ir para o Google

<img /> (Imagem)

É uma tag autocontida usada para exibir fotos ou ilustrações na tela. Ela não guarda texto dentro dela, por isso usa duas propriedades essenciais:

Atributo src: Significa Source (Fonte). É onde você digita o caminho ou o link de internet onde a imagem está salva.

Atributo alt: Significa Alternative (Texto Alternativo). É uma descrição por texto da imagem. Ela é fundamental para acessibilidade (lida por cegos) e aparece na tela caso a imagem quebre ou não carregue.

            o segundo azul escrito "T", o terceiro amarelo escrito "M" e o último verde escrito "L". 
            As escritas estão em todas as faces com a cor branca' />
