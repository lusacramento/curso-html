Listas

Para criar qualquer lista no HTML, nós sempre usamos uma tag mãe (que define o tipo de lista) trabalhando em dupla com as tags filhas (que são os itens da lista).


<li></li> (Item da Lista)

Significa List Item (Item da Lista).

O que faz: É a tag usada para criar cada linha ou item dentro de uma lista. Ela nunca deve ficar solta no código; precisa sempre estar guardada dentro de uma tag <ul> ou <ol>. 


        Código
        <p>Lista de Compras</p>
        <ul>
            <li>Arroz</li>
            <li>Feijão</li>
            <li>Café</li>
        </ul>

Exemplo:

Lista de Compras

  • Arroz
  • Feijão
  • Café

<ul></ul> (Lista Não Ordenada / Com Marcadores)

Significa Unordered List (Lista Não Ordenada).

O que faz: Cria uma lista onde a ordem dos fatores não importa. O navegador adiciona automaticamente aquela bolinha preta (bullet point) antes de cada item <li>. 


        Código:
        <p>Procedimentos:</p>
        <ol>
            <li>Abra o VS Code</li>
            <li>Crie um arquivo index.html</li>
            <li>Escreva seu código</li>
        </ol>

Exemplo:

Procedimentos:

  1. Abra o VS Code
  2. Crie um arquivo index.html
  3. Escreva seu código

Atributo type=""

Na lista ordenada (<ol>), você pode usar o atributo type para mudar os números comuns por outros sistemas de ordenação:

Para letras maiúsculas(A, B, C...)


        Código:
        <p>Procedimentos:</p>
        <ol type="A" >
            <li>Abra o VS Code</li>
            <li>Crie um arquivo index.html</li>
            <li>Escreva seu código</li>
        </ol>

Exemplo:

Procedimentos:

  1. Abra o VS Code
  2. Crie um arquivo index.html
  3. Escreva seu código
