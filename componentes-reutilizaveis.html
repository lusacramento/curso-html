Componentes Reutilizáveis

Para evitar a repetição manual de códigos que aparecem em múltiplas páginas (como menus de navegação e rodapés), podemos isolar esses layouts em arquivos independentes e embuti-los onde for necessário.


<iframe></iframe> (Janela Incorporada)

Significa Inline Frame (Quadro Incorporado).

O que faz: Cria uma espécie de "janela" ou abertura na página atual que permite renderizar e exibir um segundo documento HTML completamente separado e independente ali dentro.


Atributo src=""

O atributo src (source) define o caminho ou endereço do arquivo HTML externo que você deseja injetar na janela do <iframe>.


Atributo frameborder=""

O atributo frameborder define se a janela externa terá uma borda divisória ao redor dela. Definir frameborder="0" remove qualquer linha divisória padrão do navegador, integrando o visual perfeitamente ao seu layout principal.


Atributo target="" (Destino dos Links)

Quando usamos links <a> dentro de uma página que está embutida em um <iframe>, o comportamento padrão do navegador é abrir o novo link dentro da própria janelinha. Para mudar isso, usamos o atributo target nos links do arquivo embutido:

O valor target="_parent" avisa ao navegador para quebrar a janela do iframe e abrir o link na página principal do site (a página mãe). Outro valor comum é o target="_blank", que abre o link em uma nova aba separada. 

<!-- Código que deve ir DENTRO do arquivo embutido (ex: menu.html) -->
<nav>
    <a href="index.html" target="_parent">Início</a>
    <a href="tabelas.html" target="_parent">Tabelas</a>
    <a href="https://google.com" target="_blank">Abrir Google em Nova Aba</a>
</nav>
