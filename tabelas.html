Tabelas

Para criar qualquer tabela no HTML, nós estruturamos os dados em linhas e colunas através de um conjunto de tags específicas, onde cada linha agrupa células de cabeçalho ou de dados comuns.


<table></table> (A Tabela)

Significa Table (Tabela).

O que faz: É a tag principal que envolve toda a estrutura da tabela. Ela avisa ao navegador onde a área de dados tabelados começa e termina.


<tr></tr> (Linha da Tabela)

Significa Table Row (Linha da Tabela).

O que faz: É usada para criar uma linha horizontal dentro da tabela. Todo o conteúdo de cabeçalhos ou dados deve obrigatoriamente ficar guardado dentro de uma <tr>.


<th></th> e <td></td> (Células da Tabela)

<th> significa Table Header (Cabeçalho da Tabela) e <td> significa Table Data (Dado da Tabela).

O que faz: A tag <th> cria uma célula de título da coluna (o texto fica em negrito e centralizado automaticamente). A tag <td> cria uma célula comum de dado (texto normal alinhado à esquerda).


Atributo border=""

O atributo border define a largura em pixels das linhas divisórias da tabela. Por padrão as tabelas nascem invisíveis (border="0"). Definir border="1" desenha linhas finas delimitando os dados.

Como ela funciona?

O valor inserido define a espessura da linha em pixels. O valor border="0" deixa a tabela transparente, border="1" cria linhas finas tradicionais e valores maiores (como border="5") criam uma moldura externa mais grossa e tridimensional.


Exemplo de tabela


        Código:
        <table border="3">
        <tr>
            <th>Nome</th>
            <th>Idade</th>
            <th>E-mail</th>
        </tr>
        <tr>
            <td>Ana Silva</td>
            <td>28</td>
            <td>ana@email.com</td>
        </tr>
        <tr>
            <td>Bruno Costa</td>
            <td>34</td>
            <td>bruno@email.com</td>
        </tr>
        <tr>
            <td>Carla Souza</td>
            <td>22</td>
            <td>carla@email.com</td>
        </tr>
    </table>
